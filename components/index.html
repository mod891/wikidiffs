¡Bienvenido a WikiDiffs!

Esta web muestra diferencias hechas en Wikipedia por los criminales que tienen hackeado mi teléfono y conexiones. Se puede apreciar qué cambian, cuándo y en qué o quién se interesan.

Hay ediciones legítimas, reediciones de la historia, muchos deshechos y a veces mensajes para otros usuarios.

En el vídeo explico en detalle la motivación para hacer esta web con humor, porque mejor reir que llorar ¿no?

FAQ

  • El icono abre un enlace externo a la fuente de wikipedia. Los demás enlaces cargan contenido desde la base de datos.

  • En Notas se pueden guardar notas y diferencias. Hay más de 25000 diferencias cuando carga la base de datos completa.

  • Usuarios son los que han realizado la edición anterior al , a veces el mismo rango IP.

  • Las categorías y información del enlace costó hacerlas con chatGPT, no seguía las instrucciones muchas veces.

  • Con una pequeña modificación del bot se puede crear otra base de datos de cualquier usuario o rango de ip y usarla en esta web.

  • Pulsa el botón rojo para borrar la base de datos del navegador y notas guardas.
