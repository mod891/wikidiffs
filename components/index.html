¡Bienvenido a WikiDiffs!

Esta web muestra las diferencias hechas en páginas de wikipedia por los criminales que tienen hackeado mi teléfono y conexiones. Se puede apreciar qué cambian, cuándo y en qué o quién se interesan.

En el vídeo explico mi problema y la motivación para hacer esta web con humor, porque mejor reir que llorar ¿no?

  • En Notas se pueden guardar notas y diferencias concretas. Hay más de 25000 diferencias cuando carga la base de datos completa.

  • Usuarios son los que han realizado la edición anterior al , a veces el mismo rango IP.

  • Las categorías y información del enlace costó hacerlas con chatGPT, no seguía las instrucciones muchas veces.

  • Con una pequeña modificación del bot se puede crear otra base de datos de cualquier usuario o rango de ip y usarla en esta web.
